A visual catalog of Arkham House and Mycroft & Moran. Use it to browse the imprints and track what you've collected, what you have on order, and what you still want.

Marking books

Open a card and tap Collect to cycle: on order → in your collection → remove. Tap Want to flag titles you are still hunting.

Header filters

  • COLLECTION — show everything you've marked, collected or have on order. Click again to narrow to on-order titles only; click once more to show the full catalog.
  • WANT — show only your want list.
  • MYCROFT & MORAN — click to show that imprint only, click again to hide those titles, click again to reset.

Search narrows the grid; filters combine with search. Your lists stay in the browser, or sync via an optional private GitHub Gist.

Collection storage

Collection storage

Saves your collection to a private GitHub Gist so you can open it on another browser. Requires a GitHub token.

Security note

Your token is saved in this browser—anyone with device access can read it and use your GitHub Gist. Use a throwaway account with a gist-only PAT, not your main GitHub. Use at your own risk.

How to set up GitHub Gist sync
  1. Create a throwaway GitHub account (recommended; not your personal one).
  2. On GitHub: Settings → Developer settings → Fine-grained personal access tokens → Generate new token.
  3. Grant Gists read and write only; generate and copy the token (shown once).
  4. Select Sync with GitHub Gist, paste the token, and click Connect. Sync stays off until connect succeeds. If that account already has sync data, it loads from the Gist. Closing settings or a failed connect returns you to this device only.
  5. To move a local collection to GitHub Gist: stay on This device only, export CSV, switch to GitHub Gist sync, connect, then import CSV.
  6. On another browser or device, connect with the same token to load the same Gist. Use Clear to remove the saved token from this browser.
